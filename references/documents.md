# 提出先と書類

> 🔴 **提出先は1つではない。国・都道府県・市区町村の3系統がある。**
> そして**添付書類の要否は提出先ごとに違う**（統一されていない）。

## 3系統の構造

| 税目 | 提出先 | 出すもの |
|---|---|---|
| 国税（法人税） | **税務署** | 法人設立届出書 ＋ **青色申告承認申請書** |
| 都道府県税 | 県税事務所 / 都税事務所 | 法人設立・開設届出書 |
| 市区町村税 | 市役所の法人課税担当 | 法人設立・開設届出書（第1号様式など） |

### 🔴 東京23区は例外

特別区は**都が課税**するため、**市区町村への届出が不要**（都税事務所に一本化）。
「3か所に出す」は23区外の話。**自分の本店がどちらかを最初に確認する。**

## 添付書類（実例・1社ぶん）

**自治体ごとに違う。必ず自分で確認すること。**

| 提出先 | 定款の写し | 登記事項証明書 | 備考 |
|---|:---:|:---:|---|
| 税務署（国税） | 要 | **不要** | 平成29年4月1日以後（平成29年度税制改正） |
| 県税事務所 | 要 | 不要だった | 自治体により異なる |
| 市（法人課税） | 要 | **コピーが必要だった** | 原本提出ではない |

→ この例では**謄本のコピーが要るのは1か所だけ**だった。
「全部に添付」と思い込むと、**謄本を余分に取得する**ことになる。

## 登記事項証明書（謄本）の扱い

| 項目 | 内容 |
|---|---|
| 取得先 | 法務局（どこの法務局でも取れる）／オンライン請求 |
| 費用 | 窓口 600円／オンライン請求・郵送受取 500円 前後 |
| **有効期限** | 書類自体に期限はないが、**提出先が「発行から3ヶ月以内」を求めることが多い** |
| 種類 | **履歴事項全部証明書**を取るのが基本（現在事項証明書だと過去の変更が載らない） |

🔴 **取りすぎない。** 3ヶ月で「新しさ」を失うので、
必要になる時期を見てから取る。法人口座の申込に使う分を残しておくこと。

### 印鑑証明書とワンストップ

登記完了後に**印鑑カードの交付**を受けると、
同じ窓口で**登記事項証明書＋法人印鑑証明書**をまとめて取得できる。
法務局へ行く回数を1回に減らせる。

## 記入値を1枚の表にまとめておく

**全書類で同じ値を書く。** 揺れると照合で止まる。
設立時に次の表を作り、全部の書類をこれから転記する。

| 項目 | 注意点 |
|---|---|
| 商号 | 🔴 **登記の表記どおり**（全角/半角、「合同会社」の位置） |
| フリガナ | 登記の内容と一致させる |
| 法人番号（13桁） | 法人番号公表サイトで確認できる |
| 本店所在地 | 🔴 **丁目・番地の表記まで登記どおり**（「1丁目4番3号」と「1-4-3」を混ぜない） |
| 設立年月日 | **登記申請日**であって、登記完了日ではない |
| 事業年度 | 定款の記載どおり |
| 資本金 | 円単位 |
| 代表者氏名 | 🔴 **異体字は登記どおり**（→ `notation.md`） |
| 代表者住所 | 個人の住民票の住所 |
| 事業の目的 | 定款どおり（要約しない） |
| 事業内容（実態） | 業種を平易に。「情報通信業（受託開発・自社Webサービス）」など |
| 給与支払の有無 | 役員報酬0・従業員なしなら「なし」 |
| 消費税 | 資本金1,000万円未満は設立2期は原則免税 |
| 関与税理士 | いなければ「なし」 |

## 出し方の選択肢

| 方法 | 長所 | 短所 |
|---|---|---|
| **郵送** | 窓口に行かなくてよい。控えが返る | 到達確認は自分でする |
| 窓口 | その場で収受印がもらえる。質問できる | 開庁時間に行く必要がある |
| e-Tax / eLTAX | 電子で完結 | 初回の利用者識別番号・電子証明書の準備が要る |

**設立時の1回だけなら郵送が現実的。** e-Tax の初期設定に時間を取られるより速い。
🔴 **控え用のコピー＋返信用封筒＋切手**を必ず同封する。
