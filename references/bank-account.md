# 法人口座（落ちる前提で設計する）

> 🔴 **バーチャルオフィス本店 × 設立直後は、落ちる。**
> 落ちてから考えると詰むので、最初から「1行目は落ちるかもしれない」前提で組む。

## 実例：提出の翌日に否決

```
申込        → 事業内容確認書類を提出
   ↓ 翌日
否決の通知   （理由は非開示）
```

**翌日に返ってきた**ということは、実態調査ではなく**形式要件で弾かれている**。
つまり「事業内容が疑われた」のではなく、**条件に合わなかった**。

### 提出していたもの

- 自社サイト（会社概要ページ・サービスページ）
- 取引先1社宛の請求書 ＋ 入金が分かる口座明細

→ **請求書1社分だけでは「継続取引の厚み」を示せていなかった**可能性が高い。

## 落ちる側の条件（心当たりの優先度順）

| # | 条件 | 自分で変えられるか |
|---|---|:---:|
| 1 | **本店がバーチャルオフィス** | ❌（変えると法人化の目的を壊す） |
| 2 | **設立から日が浅い** | ❌（待つしかない） |
| 3 | 資本金が小さい・従業員なし・役員報酬0 | △ |
| 4 | 🔴 **事業実態の資料が薄い** | ✅ **ここだけコントロールできる** |

1について: 賃貸借契約書が確認できないため信用度が下がるのは**全行共通**。
「VO事業者と同系列の銀行なら通る」も成り立たない（実例では同系列でも否決された）。

2について: 「VO登記は設立半年経過が要る」という指摘は複数の行で聞く。
**設立直後に申し込んで落ちたら、半年待って再申請する**のが基本線。

## 🔴 4が本丸 — そして、ここに循環がある

> 取引先に出す請求書には**法人口座の振込先**を書く。
> しかし法人口座の審査には、**法人名義の取引実績**が要る。
> 口座がないと法人名義の請求書が出せず、請求書がないと口座が作れない。

### 解き方

**入金先を代表者個人口座にしたまま、請求書だけ法人名義で発行する。**

- 振込先が個人口座であること自体は問題にならない
- 会計上は**役員借入金／立替**として処理する
- これで「**法人名義の継続取引**」の証跡が作れる
- 複数月・複数社ぶん溜めてから再申請する

🔴 **取引先への連絡が必要**（請求元の名義が変わるため）。
入金先の変更は口座ができてからでよい、と伝えれば通常は問題にならない。

## 落ちたあとにやること

| やること | 中身 |
|---|---|
| **同じ行に再申請しない** | 否決後は**半年程度空ける**のが通例。すぐ出しても同じ結果になる |
| **別の行に並行して出す** | ネット銀行は書類が最小で速い。**1行に賭けない** |
| **自社サイトを厚くする** | 「具体的な業務内容が書かれたHP」は**VO案件の必須条件**。下記参照 |
| **固定電話を用意する** | 携帯のみは減点。VOの電話転送オプションで足りることが多い |
| **事業計画書を審査向けに整える** | 売上見込みと資金の流れを明記する |
| **表記を一字一句そろえる** | 申込内容・HP・登記で1文字でも違うと減点になり得る（→ `notation.md`） |

### 自社サイトに必ず載せるもの

会社概要ページに以下を全部書く。**1つでも欠けると「実体が確認できない」判定に寄る。**

- [ ] 商号（**登記どおりの表記**）
- [ ] 本店所在地（**登記どおりの表記**）
- [ ] 法人番号
- [ ] 代表者名
- [ ] 連絡先（メール＋電話）
- [ ] 設立年月日
- [ ] 事業内容（**具体的に**。「ITサービス」ではなく何を誰に売っているか）

## ❌ やってはいけない対処

**「落ちたから本店を自宅に移す」は、たいてい間違い。**

| 失うもの | 中身 |
|---|---|
| 費用 | 本店移転の変更登記（**登録免許税3万円**〜。管轄外への移転はさらに高い） |
| 手間 | D-U-N-S・Apple・Google・取引先・サイト・請求書の住所を**全部やり直す** |
| 🔴 **目的そのもの** | **個人住所を非公開にする**という法人化の目的が消える |

口座は他行で作れる。**住所は簡単には戻せない。**

## 銀行の選び方

| 種別 | 特徴 |
|---|---|
| **ネット銀行** | 書類が最小・最短翌営業日〜。振込手数料が安い。**VO でも通る余地がある** |
| メガバンク | 信用度は高いが審査が厳しい。VO・設立直後は通りにくい |
| 地銀・信用金庫 | **VOに最も厳しい**。地元での実店舗・実態を重視する |

**設立直後はネット銀行を複数、並行して申し込むのが現実的。**
メガバンクは実績が積み上がってから追加する（法人の2行持ちは普通）。

### 会計ソフトの設立支援サービス経由で申し込む

会計ソフト各社が提供する会社設立サービスには**銀行口座開設の導線**がある。

- 入力済みの法人情報が引き継がれる（入力ミスによる表記ズレを減らせる）
- 振込手数料の優遇などの特典がつくことがある

## 📮 開設できたら届くもの（受取設計）

🔴 **転送不要の簡易書留で届く。受け取り損ねると口座が消える。**

```
保管期限超過で返戻
   → 銀行からメール連絡のうえ再送
      → 再送分も返戻したら → カード・口座の利用制限または解約
```

**VOを本店にしている場合は、郵便の転送設定を事前に確認する。**
「転送不要」郵便はVO事業者が転送できない場合があるので、
**VO事業者の取り扱いを申込前に確認しておくこと。**

## 口座ができるまでのつなぎ

| 困ること | つなぎ方 |
|---|---|
| 入金先がない | 代表者個人口座で受け、**役員借入金／立替**で処理 |
| 法人カードが作れない | 個人カードで立替 → **創立費／開業費**で計上。明細と領収書を保存 |
| Apple の有料アプリ契約 | **組織登録・無料アプリ配信は口座なしで進む**。有料契約だけ後ろにずらす |

🔴 **口座待ちで税務届出の期限を落とさないこと。**
設立届も青色申告承認申請も、**法人口座が無くても提出できる**。
