# 表記を一字一句そろえる

> 🔴 **登記した瞬間、商号と住所の表記が「正」として固定される。**
> 以降に作るものは全部それに合わせる。ズレると審査で落ちるか、後で全部やり直す。

## そろえる先（依存の順番）

```
定款
 └→ 登記            ← ここで「正」が確定する
     └→ 法人番号公表サイト（国税庁が自動生成）
     └→ 税務署 / 県 / 市への届出
     └→ 法人口座の申込
     └→ D-U-N-S® Number（D&B）
          └→ Apple Developer Program（組織）  ← 🔴 D&Bから住所を自動入力する
          └→ Google Play Console（組織）
     └→ 自社サイトの会社概要
     └→ 請求書・契約書
```

🔴 **Apple は D-U-N-S の住所を引いてくる。**
つまり **登記 → D&B → Apple の3層が一致していないと、Apple 側だけ直すことができない**。
D&B の登録内容を直してから Apple に反映させる、という手順になり、時間がかかる。

**先に登記の表記を確定し、それを1文字も変えずに下流へ流す。** これに尽きる。

## 事故りやすい4パターン

### 1. 全角 / 半角

```
登記:  合同会社ｅｘａｍｐｌｅ   ← 全角
誤記:  合同会社example         ← 半角。別名義として扱われうる
```

商号にアルファベットを使う場合、**定款の時点でどちらにするか決める**。
登記後に気づいても変更登記が要る。

### 2. 丁目・番地の表記

```
登記:  ○○町1丁目4番3号 △△ビル402
誤記:  ○○町1-4-3 △△ビル402
```

**ハイフン省略形は「同じ住所」だが「同じ表記」ではない。**
口座審査など照合が厳格な場面で減点・差し戻しになる。

### 3. 異体字・旧字体（該当する人には最大の地雷）

対象になりやすい文字の例:

| 文字 | Unicode | 新字体 |
|---|---|---|
| 栁 | U+6801 | 柳 |
| 髙 | U+9AD9 | 高 |
| 﨑 | U+FA11 | 崎 |
| 𠮷 | U+20BB7 | 吉 |
| 濵 | U+6FF5 | 濱 / 浜 |
| 邊 / 邉 | U+9089 / U+9089 | 辺 |

**システムによって扱えたり扱えなかったりする。事前に一覧はない。**

実際に起きたこと（代表者名に U+6801 を含むケース）:

| 場面 | 結果 |
|---|---|
| 電子定款の作成（行政書士経由） | ✅ 扱えた |
| **登記のオンライン申請**（一部サービスのベータ機能） | ❌ **扱えず、書面申請に切り替えた** |
| 銀行の申込フォーム | ❌ 受け付けず、**新字体で申込** |
| 税務署・県・市の書類 | ✅ **登記どおりの異体字で記入** |

→ **「公的書類は異体字、一部のWebフォームは新字体」という二重運用**になる。
これは間違いではなく、そういうものとして運用するしかない。

🔴 **どちらをどこで使ったかを記録すること。**
記録がないと、後で不整合が出たときに原因を追えない。

#### 設立の最初に確認する

```
代表者名に異体字（U+XXXX）が含まれます。
オンライン登記申請でこの文字が扱えるか確認したうえで、
扱えない場合の代替手段（書面申請）の手順と、追加で必要になるものを教えてください。
```

**書面申請に落とすこと自体は問題ない。** 登記の結果は同じ。
ただし**申請方法を切り替えるぶん日程が動く**ので、早く分かるほどよい。

### 4. 外部サービス側の登録ミス（自分では気づけない）

実例:

```
登記:              ○○県△△市□□区…
VO事業者の管理画面: ××都△△市□□区…   ← 都道府県だけが誤っていた
```

**自分が入力した値ではないので疑わない。** これが怖い。

**実害**: VO事業者が発行する「利用契約に関する証明書」に誤住所が印字されると、
口座審査で提出する書類の住所が登記と食い違う。

→ **外部サービスに登録されている自社情報を、登記簿と機械的に突き合わせる。**
`../scripts/check_notation.py` がその道具。

## 突き合わせる対象の棚卸し

設立後、次の場所に登録された自社情報を全部見に行く。

- [ ] 法人番号公表サイト（国税庁が登記から自動生成。**ここが登記の写しになる**）
- [ ] バーチャルオフィス / 賃貸の契約情報
- [ ] 法人口座の申込内容
- [ ] D-U-N-S®（D&B）の登録内容
- [ ] Apple Developer / Google Play Console の組織情報
- [ ] 自社サイトの会社概要ページ
- [ ] 請求書テンプレート
- [ ] 会計ソフトの事業所設定
- [ ] ドメイン登録（Whois）の組織名

## 使う道具

```bash
# 登記簿の表記を基準に、各所の表記を突き合わせる
python3 .claude/skills/company-setup/scripts/check_notation.py --help
```
